\# DrumHero - Vintage Rock Experience



Projeto de interface web moderna sobre a história, técnicas e universo da bateria no rock clássico. Trabalho desenvolvido para a disciplina de SCOM.



\## Tecnologias Utilizadas

\- HTML5 Semântico

\- CSS3 Moderno (Flexbox, CSS Grid, Variáveis CSS)

\- JavaScript Vanilla



\## Instruções de Execução

Para executar o projeto localmente:

1\. Clone ou baixe este repositório.

2\. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Google Chrome, Mozilla Firefox, Microsoft Edge).

\*Não é necessária instalação de dependências ou servidores locais.\*
