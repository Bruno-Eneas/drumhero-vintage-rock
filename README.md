DrumHero - Vintage Rock Experience 

Projeto de interface web moderna focado em documentar a história, técnicas e o universo da bateria no rock clássico. Trabalho acadêmico desenvolvido para a disciplina de Sistemas Computacionais (SCOM).

Objetivos do Projeto
- Aplicar conceitos modernos de engenharia de interface.
- Garantir acessibilidade plena (WCAG 2.2 AA).
- Atingir alta performance e responsividade (Mobile First).

Tecnologias Utilizadas
- HTML5: Estruturação semântica.
- CSS3: Flexbox, CSS Grid e media queries.
- Git/GitHub:** Versionamento de código.

Como Executar
Por se tratar de um site estático, não é necessária a instalação de dependências complexas.
1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno.
